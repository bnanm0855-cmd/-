# مملكة الجيمر — واجهة الزوار

واجهة مستقلة للزوار، مصممة بالعربية وبدعم RTL، مع أولوية لشاشات الهواتف.

## الملفات
- `index.html` — الصفحة والهيكل.
- `style.css` — التصميم المتجاوب.
- `app.js` — البحث والتصنيفات ورفع ملفات HTML وتجربتها وتنزيلها واقتراح التعديلات.
- `manifest.webmanifest` و`sw.js` — أساسيات التثبيت كـ PWA والتخزين المؤقت.

## التشغيل
افتح مجلد `visitors` عبر خادم محلي أو انشره على استضافة صفحات ثابتة. بعض خصائص PWA تحتاج HTTPS أو localhost.

## تنبيه حول مرحلة قاعدة البيانات
هذه مرحلة واجهة الزوار فقط، قبل ربط SQL/Supabase. لذلك ملفات الألعاب والاقتراحات التي يضيفها الزائر الآن تحفظ محلياً في متصفحه على نفس الجهاز، ولا تظهر تلقائياً في لوحة الإدارة أو للزوار الآخرين. يلزم تنفيذ ربط قاعدة البيانات والتخزين السحابي والصلاحيات في المرحلة الثالثة قبل النشر العام لاستقبال ملفات الزوار ومشاركتها بين الأجهزة.
